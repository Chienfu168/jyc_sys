建立日期：2026-07-22

專案名稱：游榮吉教育基金會智慧營運管理系統  
英文名稱：JYC Foundation Management Information System  
簡稱：JYC Foundation MIS  
建議網址：`mis.jyc.org.tw`

---

## 1. 專案背景

本系統為「財團法人新北市游榮吉教育基金會」內部營運管理系統，目標是整合目前分散於 Excel、Word、Google Drive、紙本表單與網站中的行政與業務資料，建立可追溯、可統計、可擴充的基金會營運資料庫。

基金會主要業務包含：

1. 學校參訪與教育需求盤點
2. 深耕教育長期課程
3. 公益倡議與教育活動
4. AI、STEAM、藝術、雙語等教育課程
5. 夏冬令營及教育營隊
6. 教育論壇
7. 國際交流
8. 師資媒合與教師管理
9. 公益合作與合作單位管理
10. 財務、預算、請購及核銷管理
11. 活動成果、照片、新聞及媒體紀錄
12. 年度工作成果與統計報表

系統核心設計原則為：

> 學校－專案－活動／課程－財務－成果

所有功能與資料庫設計都應圍繞此關聯架構展開。

## 3. 開發基本原則

1. 資料集中管理  
   避免同一份資料重複存在 Excel、Word 或不同系統中。例如學校基本資料只建立一次，後續專案、活動、課程直接關聯該學校。

2. 關聯式資料設計  
   核心資料關係應由學校延伸至專案、課程、活動、師資、財務、成果與年度統計。

3. 重要資料可追溯  
   每筆重要資料至少記錄建立人、建立日期、修改人、修改日期。必要時增加操作紀錄、狀態變更紀錄與審核紀錄。

4. 優先使用標準 CRUD  
   大部分模組以 Create、Read、Update、Delete、Search、Filter、Export 為主要操作方式，優先使用 Filament Resource、Table、Form、Widget 減少不必要客製。

5. 安全與權限優先  
   敏感資料需透過角色權限控管，重要操作需保留 Audit Log。

## 8. 使用者角色與權限

建議使用 Role-Based Access Control。

角色初稿：

1. Super Admin：全部功能
2. 系統管理員：管理系統資料與帳號
3. 執行長／主管：查看全部營運資料與審核
4. 企劃人員：操作學校、專案、活動、成果、文件
5. 財務／會計：操作收入、支出、預算、核銷、財務附件
6. 講師：查看自己的課程、填寫課程日誌、上傳照片、查看教學紀錄
7. 董事：Dashboard、統計報表、年度成果，原則上 Read Only

敏感資料包含銀行帳戶、個人身分資料、財務憑證、薪資與捐款資料，必須設定不同權限。

## 12. 程式開發原則

1. 遵守 Laravel Coding Standards
2. 使用 Migration 管理資料庫
3. 不直接手動修改正式資料庫 Schema
4. 使用 Model Relationship
5. 使用 Form Request 或 Filament Validation
6. 重要操作使用 Policy
7. Sensitive data 避免直接暴露
8. 不將 API Key 寫在程式碼
9. 使用 `.env`
10. 所有程式納入 Git 版本控制
11. 重要資料優先使用 Soft Delete
