# 開發順序

## Phase 0：環境與專案初始化

1. 安裝 PHP 8.3+
2. 安裝 Composer
3. 安裝 Node.js
4. 安裝 MySQL
5. 建立 Laravel 專案
6. 設定 `.env`
7. 安裝 Filament 5
8. 安裝 Spatie Permission

## Phase 1：資料庫與 Model

1. 建立年度 `fiscal_years`
2. 建立學校 `schools`
3. 建立學校聯絡人 `school_contacts`
4. 建立講師 `teachers`
5. 建立合作單位 `partners`
6. 建立年度工作計畫 `work_plans`
7. 建立專案 `projects`
8. 建立課程 `courses`
9. 建立課程日誌 `course_sessions`
10. 建立活動 `activities`
11. 建立預算 `budgets`
12. 建立收入 `incomes`
13. 建立支出 `expenses`
14. 建立成果 `outcomes`
15. 建立附件 `attachments`
16. 建立年度報告 `annual_reports`

## Phase 2：Filament Resources

1. 學校管理
2. 講師管理
3. 合作單位管理
4. 年度管理
5. 專案管理
6. 深耕教育課程
7. 課程日誌
8. 活動紀錄
9. 預算管理
10. 支出管理
11. 附件管理

## Phase 3：Dashboard 與報表

1. 年度統計卡片
2. 專案狀態統計
3. 預算執行率
4. 活動與服務人次統計
5. 學校合作歷程
6. 專案成果摘要
7. 年度工作報告資料匯出

## Phase 4：權限與行動端優化

1. 角色與權限
2. 講師手機填寫課程日誌
3. 活動照片上傳
4. 財務敏感欄位保護
5. 基礎 Audit Log
