# 基金會管理系統後續建置順序

建議採取「基礎資料先穩定、財務流程先閉環、再補業務與人事」的順序，避免後續模組反覆改資料結構。

## 1. 基礎設定

- 基金會基本資料
- 使用者、角色與權限
- 銀行帳戶與零用金基本項目
- 列印抬頭、簽署欄與表單版型

## 2. 財務核心

- 銀行帳戶交易
- 零用金管理
- 預算經費表
- 收支紀錄
- 會計科目與傳票
- 月報、年報與 PDF 輸出

## 3. 業務管理

- 工作計畫
- 專案管理
- 活動管理
- 講師管理
- 行事曆管理

## 4. 人事與支出

- 人事基本資料
- 薪資管理
- 人事請假
- 講師支出費用
- 出差費用
- 志工管理

## 5. 稽核與治理

- 簽核流程
- 異動紀錄
- 文件附件
- 權限稽核
- 備份與還原

## 6. 線上維運

- GitHub Release 一鍵更新
- migration 檢查
- 更新前備份
- 錯誤回復流程
